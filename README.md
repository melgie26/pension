# Alberta Edition — Pension & Tax Visualizer

An Alberta adaptation of the original BC retirement visualizer. Open `index.html`
in a browser to use it; no build or installation step is required.

## What has been adapted

- 2026 Alberta personal income-tax brackets
- 2026 Alberta basic personal amount ($22,769)
- 2026 federal brackets, CPP and EI inputs
- LAPP terminology, standard pension formula and 2026 COLA information
- Neutral Alberta branding and a working stand-alone HTML download

## Important limitations

This is an independent, unofficial educational estimate, not tax, legal,
pension, actuarial, investment, financial, or retirement-planning advice.
The tax display is intentionally simplified and is not a replacement for a tax
return, CRA's Payroll Deductions Online Calculator, or an official LAPP estimate.
It does not model every credit, surtax, benefit, OAS recovery-tax rule, pension
splitting scenario, employer agreement, or individual firefighter arrangement.

## Publish with GitHub Pages

1. Create or open your own GitHub repository.
2. Upload `index.html`, `README.md`, and `LICENSE` to the repository's top level.
3. In the repository, open **Settings**, then **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait a few minutes. GitHub will show the public address on the Pages screen.

Before presenting the page as an official association resource, obtain permission
for the association name/logo and have the pension assumptions reviewed by LAPP
or the applicable employer/union pension specialist.
